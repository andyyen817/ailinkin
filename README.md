# ailinkin · AI 客户搜索与客户管理

本仓库保存已构建版本的应用源码、数据库定义和离线回归测试。
发布清单 `release-manifest.json` 记录生产源码的 SHA-256，可用于核对云端构建来源。

## 本地构建与测试

使用 Node.js 22.12–22.x 或 24.x，按锁文件安装依赖：

```sh
npm ci
npm run db:generate
npm test
npm run build
```

数据库与 Redis 连接、认证密钥、供应商账号由运行环境私有配置提供。
`prisma/*.sql` 包含租户隔离、最小权限和后台任务规则；生产变更需由部署负责人审核执行。
构建本身不初始化数据库、不创建管理员、不迁移历史资料。

## 功能与运行范围

- 企业账号登录、客户维护、名单和跟进状态。
- CSV 预览、逐行导入、去重、后台导出和下载。
- 客户搜索、联系人补全和来源证据模块，按环境开关和免费限额启用。
- 禁止联系标记保留，重新导入不能清除。

正式试用环境当前关闭自动外部采集、付费调用和邮件发送。
数据迁移、供应商额度与发信功能需要独立授权及验收。

本地运行记录、客户原始资料、凭据、截图和历史验收文件由项目工作区单独保管。
GitHub 发布采用经过筛选的源码快照，原本地 Git 历史完整保留。
